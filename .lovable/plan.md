
# Noah Canter - Resume Site

A beautiful, dark-themed single-page resume website showcasing your programming journey.

## Design Approach
- **Dark & Sleek Theme**: Deep dark background with subtle gradients, accent colors (likely a cyan or purple glow), and clean typography
- **Smooth Animations**: Subtle fade-ins and hover effects for a polished feel
- **Responsive Design**: Looks great on desktop and mobile

## Sections

### 1. Hero / Header
- Your name "Noah Canter" prominently displayed with a striking headline
- Location: DFW
- Brief tagline about being an aspiring developer
- GitHub link button

### 2. About Me
- A short bio introducing yourself and your passion for programming
- Your journey learning to code through Codecademy

### 3. Skills
- Visual skill cards/badges for:
  - HTML, CSS, JavaScript (Web Development)
  - Python
- Clean icons and subtle animations on hover

### 4. Projects
- Section to showcase projects from your GitHub
- Placeholder cards you can update as you build more projects
- Links directly to your GitHub repos

### 5. Education & Learning
- Codecademy learning journey
- Any courses/certifications you're working on or have completed

### 6. Footer
- GitHub link prominently displayed
- Simple copyright/credit line

## Visual Features
- Subtle gradient backgrounds
- Glowing accent effects
- Smooth scroll navigation
- Modern card designs with hover states
